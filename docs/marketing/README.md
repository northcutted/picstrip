# Marketing

Single source of truth for everything App-Store-shaped. The release pipeline pulls from `fastlane/` directly; this directory is the human-readable index over those assets.

## What lives where

| Asset | Source of truth | What it ships into |
|-------|-----------------|--------------------|
| **App Store text** (name, subtitle, description, keywords, promotional text, URLs) | [`fastlane/metadata/<locale>/`](../../fastlane/metadata) — all 16 supported locales | Uploaded by `bundle exec fastlane submit` on every release |
| **Canonical English copy + structure for review** | [`MARKETING.md`](MARKETING.md) | Reviewed/edited by humans; mirrored back into `fastlane/metadata/en-US/` |
| **Screenshot headlines** (5 keys × 16 locales) | [`fastlane/MarketingHeadlines.xcstrings`](../../fastlane/MarketingHeadlines.xcstrings) | Read by `scripts/process_screenshots.py` at compose time |
| **Marketing screenshots** (5 screens × 2 devices × 16 locales) | [`fastlane/screenshots/processed/<locale>/`](../../fastlane/screenshots/processed) (Git LFS) | Uploaded by the `screenshots.yml` workflow |
| **Release notes** | [`fastlane/metadata/en-US/release_notes.txt`](../../fastlane/metadata/en-US/release_notes.txt) (auto-generated by semantic-release from commits) | Shipped per release; mirrored to [`CHANGELOG.md`](../../CHANGELOG.md) |
| **App icon variants** | [`docs/icons/`](../icons) | Imported into Asset Catalog manually |

## Common tasks

| Task | Command / file |
|------|----------------|
| Edit App Store description, subtitle, keywords | Edit `MARKETING.md` **and** matching `fastlane/metadata/en-US/<field>.txt` |
| Refresh marketing screenshots after a UI change | `gh workflow run screenshots.yml -f generate_new=true` |
| Rewrite a screenshot headline | Edit [`fastlane/MarketingHeadlines.xcstrings`](../../fastlane/MarketingHeadlines.xcstrings); regenerate via the workflow above |
| Add a new locale to App Store Connect text | Create `fastlane/metadata/<locale>/` with the standard `.txt` files |
| Pseudo-localize for layout smoke-test | `make localization-pseudo LANGUAGES="es"` |

## Why the duplication?

App Store Connect lets you upload metadata via fastlane's `deliver`, which reads `.txt` files from a hierarchical directory layout. Those `.txt` files are the *machine-readable* source of truth. `MARKETING.md` is the *human-readable* version — easier to read, edit, and review in a PR than 8 unlabeled `.txt` files. The convention is: edit `MARKETING.md` first, then mirror to `fastlane/metadata/en-US/` (or use the `MARKETING.md` table of fields as the spec for what to copy where).

A tighter alternative would be having `MARKETING.md` *generate* the `.txt` files, but the volume is small enough that manual mirroring is fine and avoids another build step.
