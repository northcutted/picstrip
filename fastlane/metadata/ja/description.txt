最近、誰かに写真を送りましたか？その写真には、自宅のGPS座標、撮影日時、カメラのシリアル番号などが目に見えない形で埋め込まれています。PicStripは共有前にそれらをすべて削除します — ワンタップで、100%端末内で完結。

アカウント不要。アップロードなし。トラッキングなし。きれいな写真だけ。

削除される項目
• GPS位置情報 — 各写真に埋め込まれた正確な座標
• タイムスタンプ — 撮影、編集、デジタル化の日時
• デバイス情報 — カメラのメーカー、モデル、レンズ、ソフトウェアバージョン
• 個人識別子 — 作成者名、著作権、シリアル番号
• 非公開のカメラ解析 — Apple のメーカーノートデータ（存在する場合）

設計から守るプライバシー
• すべて端末内で完結 — どこにもアップロードしません
• アカウント不要、ログイン不要、トラッキングなし
• 広告なし、アプリ内課金なし、サブスクリプションなし

なぜ信頼できるのか
• オープンソース — すべてのコードは GitHub で公開され、誰でも検証可能
• SLSA Level 3 のビルドプロベナンス — リリースごとに暗号学的に検証
• 最終バイナリにサードパーティ製 SDK はゼロ。分析もネットワーク通信もなし
• プライバシーラベル「データを収集しません」 — 最も強い回答

使い方
1. タップしてフォトライブラリから写真を選択
2. PicStripが埋め込まれたすべてのメタデータをスキャン
3. 何が見つかったかを正確に確認
4. 削除 — クリーンな写真がライブラリに即保存されます

共有拡張機能
PicStripを開かずに、写真、Safari、その他のアプリの共有シートから直接メタデータを削除できます。

ショートカットと自動化
PicStripはショートカットアクションを提供しています。読み込み時の自動削除、一括処理、既存のショートカットへの組み込みが可能です。
